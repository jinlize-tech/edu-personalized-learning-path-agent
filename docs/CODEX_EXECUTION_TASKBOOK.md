# JLZ-EDU-AG-024 Codex执行任务书

## 1. 基线

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`
- 候选来源：`CAND-023`
- 正式产品：`JLZ-EDU-AG-024` / 个性化学习路径规划
- 类型：Agent
- 批次：3
- 业务中心：11 学员成功与家庭服务中心
- 版本基线：`EDUCATION_BASELINE_V1.0.0`
- 产品版本：`1.0.0`
- 许可证：Apache-2.0

## 2. 用户、痛点与目标

- 用户：教学主管、教师、学习管理师、家长沟通人员
- 痛点：学生问题跨多个知识点和学科，教师常以一张计划表替代持续调整，难以管理阶段目标、任务量和复盘。
- 目标：围绕一个学习周期建立诊断、目标、任务、里程碑、复盘和调整的多轮路径，不混淆教学建议与正式诊断。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `learner_profile` | 学生概况 | string | 是 |
| `learning_goals` | 阶段目标 | array | 是 |
| `evidence_summary` | 学情证据摘要 | array | 是 |
| `course_schedule` | 课程安排 | array | 是 |
| `available_home_time` | 家庭可用时间 | string | 是 |
| `review_cycle` | 复盘周期 | string | 是 |
| `support_conditions` | 家庭与教师支持条件 | string | 否 |

## 4. 工作流

1. 确认目标与周期
2. 盘点证据
3. 识别关键缺口
4. 设计路径和里程碑
5. 分配任务
6. 阶段复盘
7. 根据证据调整

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点学生基本情况、学习目标、课程安排、作业/测评摘要、可用时间、教师观察、家长支持条件、周期，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕围绕一个学习周期建立诊断、目标、任务、里程碑、复盘和调整的多轮路径，不混淆教学建议与正式诊断。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按确认目标与周期 → 盘点证据 → 识别关键缺口 → 设计路径和里程碑 → 分配任务 → 阶段复盘 → 根据证据调整设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由业务负责人复核输入事实、关键假设和最终成果适用范围。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `个性化路径`
- `阶段目标`
- `里程碑`

## 7. 差异化与排重

- 与现有产品：学情分析输出诊断，学习进度跟踪记录执行；本产品跨多轮编排目标和任务，并管理调整。
- 排重检查：部分重叠；现有产品做分析或进度，本产品做多阶段路径编排和动态调整。
- 独立理由：仅使用脱敏证据即可独立规划路径，不要求安装单科教研 Agent。

## 8. 安全与人工门禁

- 复核角色：业务负责人
- 复核范围：输入事实、关键假设和最终成果适用范围
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
