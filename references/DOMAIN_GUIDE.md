# 个性化学习路径规划领域指南

## 业务问题

学生问题跨多个知识点和学科，教师常以一张计划表替代持续调整，难以管理阶段目标、任务量和复盘。

## 产品解决方案

围绕一个学习周期建立诊断、目标、任务、里程碑、复盘和调整的多轮路径，不混淆教学建议与正式诊断。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `learner_profile` | 学生概况 | 是 | 年级、学科和目标；须脱敏 |
| `learning_goals` | 阶段目标 | 是 | 优先级与周期 |
| `evidence_summary` | 学情证据摘要 | 是 | 测评、作业、课堂观察和教师反馈 |
| `course_schedule` | 课程安排 | 是 | 现有课程和可用教学资源 |
| `available_home_time` | 家庭可用时间 | 是 | 每周可投入时间与限制 |
| `review_cycle` | 复盘周期 | 是 | 建议以周或阶段为单位 |
| `support_conditions` | 家庭与教师支持条件 | 否 | 不影响核心任务时可省略 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

业务负责人应确认：输入事实、关键假设和最终成果适用范围。未经确认的内容只能作为草案。

## 主要风险

不诊断学习障碍或医疗问题；目标应可调整；家长愿望不能替代证据；儿童数据需授权和最小化。
